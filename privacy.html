Privacy Policy — Lumavisor Publisher

Last updated: 22 November 2026

Who uses this app

Lumavisor Publisher is an internal tool used only by the owner of the Lumavisor YouTube channels to publish the owner's own videos. It has no other users.

YouTube API Services

Lumavisor Publisher uses YouTube API Services (YouTube Data API v3). By using it you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies to data processed by YouTube and Google.

What data it accesses

With the owner's permission (Google OAuth 2.0), the app uses the YouTube Data API to: upload videos; set titles, descriptions, tags, thumbnails, captions, playlists and publish times; and read back the status of those videos on the owner's own channels. It does not access, collect or store data of viewers or any other YouTube users (no comments, likes, subscriptions, analytics of other channels, or scraping).

How data is used, stored and shared

The only data stored are the OAuth access/refresh tokens and the IDs of the owner's own uploaded videos. They are stored only on the owner's own computer, used only to publish and verify the owner's own videos, and never sold, shared with third parties, or used for advertising. No cookies or tracking are used.

Data retention and deletion

OAuth tokens are kept only while the tool is in use and are deleted from the owner's computer as soon as access is revoked or the tool is no longer used. The local log keeps the YouTube video IDs and upload status of the owner's own videos only until 30 days after each video goes live; after that the tool deletes them automatically, keeping only the owner's own internal episode name and publish date (to prevent uploading the same video twice). To request deletion of any data, email lumavisor@gmail.com; it is deleted within 7 days.

Revoking access

Access can be revoked at any time via the Google security settings page: security.google.com/settings/security/permissions.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
