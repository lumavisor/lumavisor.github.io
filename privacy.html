Privacy Policy — Lumavisor Publisher

Last updated: 22 November 2026

Who uses this app

Lumavisor Publisher is an internal tool used only by the owner of the Lumavisor YouTube channels to publish the owner's own videos. It has no other users.

What data it accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API to: upload videos, set titles, descriptions, tags, thumbnails, captions, playlists and publish times, and read back the status of those videos on the owner's own channels. It does not read, collect or store data of viewers or any other YouTube users.

Where data is stored

OAuth tokens and a log of uploaded video IDs are stored only on the owner's own computer. Nothing is sent to third parties, sold, or used for advertising.

Google API Services

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions; the locally stored tokens are then deleted.
