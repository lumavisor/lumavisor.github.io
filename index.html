Lumavisor Publisher

Lumavisor Publisher is a private, internal tool used only by the owner of the Lumavisor YouTube channels (Lumavisor and Lumavisor Україна).

It uploads the owner's own, original science videos to the owner's own channels and schedules them using the official YouTube Data API: title, description, tags, thumbnail, captions, playlist and publish time. It is not offered to the public and is not used to access anyone else's account.

Uses YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Information is handled according to our Privacy Policy and the Google Privacy Policy.
